# Assumptions

This file records every assumption the agent has made. Assumptions with
UNRESOLVED status must be resolved before dependent phases execute.

---

## Assumption Record Format

```
## ASM-NNN: [Short title]
- **Assumption:** [What was assumed]
- **Reason:** [Why the assumption was made — what information was missing]
- **Confidence:** [HIGH / MEDIUM / LOW]
- **Status:** [UNRESOLVED / APPROVED / REJECTED]
- **Impact:** [What would change if this assumption is wrong]
- **Citation:** [optional — ref_id, page, method, confidence; omit rather than fabricate]
- **Timestamp:** [ISO 8601]
```
