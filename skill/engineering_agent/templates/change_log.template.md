## Change Record Format

```

- **Type:** [creation / modification / deletion / correction]
- **Description:** [What changed]
- **Affected elements:** [element_ids]
- **Before:** [previous state — dimensions, position, etc.]
- **After:** [new state]
- **Reason:** [why the change was made]
- **Checkpoint:** [path to pre-change checkpoint / none]
- **Approval:** [auto / user_approved]
```
