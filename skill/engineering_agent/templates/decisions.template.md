# Design Decisions

This file records WHY each engineering decision was made. It is the design
intent memory of the project.

---

## Decision Record Format

```
## DEC-NNN: [Short title]
- **Element:** [element_id] (handle: [hex])
- **Decision:** [What was decided]
- **Intent:** [Why — the engineering reason]
- **Constraints:** [What rules this decision must respect]
- **Dependencies:** [What other elements this affects or depends on]
- **Alternatives considered:** [What else was considered and why rejected]
- **Approval:** [auto / user_approved]
- **Citation:** [optional — ref_id, page, method, confidence; omit rather than fabricate]
- **Timestamp:** [ISO 8601]
```
