must be checked before and after any modification that affects the constrained element.

## Constraint Record Format

```
## CON-NNN: [Short title]
- **Type:** [dimensional / spatial / adjacency / structural / code / user-defined]
- **Target element(s):** [element_id or element type]
- **Rule:** [Formal constraint: element.property operator value unit]
- **Standard/Source:** [building code, user requirement REQ-NNN, engineering judgment]
- **Priority:** [HIGH (cannot be violated) / MEDIUM / LOW (preference only)]
- **Verified:** [false / true — timestamp]
```
